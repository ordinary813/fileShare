# fileShare

## Description
FileShare is a Peer-2-Peer secure file sharing platform utilizing a centralized tracker for network management and discovery.

## How it works
### First time booting up
1. The user will be requested to select files for other users to be able to download, which will then be saved into a file tracking file (txt format).
2. The user will choose a port to listen for outside connections.
### Using FileShare
1. The user will be shown a menu for usage:
    * Add a file
    * Download a file
    * Available peers
    * Available files in the network
    * ()
